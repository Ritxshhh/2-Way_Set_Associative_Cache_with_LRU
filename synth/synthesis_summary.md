# FPGA Synthesis Summary

**Target Device:** Xilinx Artix-7 `xc7a35tcsg324-1`  
**Tool:** Vivado Design Suite v2022.2 (out-of-context synthesis)  
**Target Clock Constraint:** 10.000 ns (100.00 MHz nominal)

> **⚠ 2-way figures need a Vivado re-run before use.** The 2-way cache stores
> 2 ways × 64 sets × (128 data + 22 tag) = 19,200 bits, and all of it is
> observable (full lines are written back to memory). At 64 bits per LUT that
> needs at least 300 LUTs as distributed RAM, but `cache_2way_utilization.rpt`
> reports 76. An independent Yosys `synth_xilinx` run maps the same RTL to
> 300 × `RAM64X1S` and 520 flip-flops. Re-run `synth_cache_2way.tcl` and
> replace the 2-way reports and the numbers below. The direct-mapped flip-flop
> count (19,374) is consistent with Yosys (19,716).

## 2. Architectural Analysis of FPGA Implementation

### Memory Inference & Register Utilization
- **Direct-Mapped Cache (`direct_mapped_cache.v`)**:
  The monolithic baseline implementation includes an asynchronous reset loop over all 128 cache lines:
  ```verilog
  for (i = 0; i < NUM_LINES; i = i + 1) begin
      data_mem[i]  <= 128'd0;
      tag_mem[i]   <= 21'd0;
      valid_mem[i] <= 1'b0;
      dirty_mem[i] <= 1'b0;
  end
  ```
  Because hardware block RAMs and distributed RAM primitives cannot be cleared in a single clock edge upon reset, the synthesis tool was forced to infer discrete Flip-Flops for the entire 16,384-bit data store and 2,688-bit tag store. This caused register utilization to explode to **19,374 FFs** (consuming 46.57% of the entire xc7a35t chip) and required substantial multiplexer trees (**2,428 LUTs**).

- **2-Way Set-Associative Cache (`cache_2way_top.v`)**:
  The modular design cleanly isolated RAM storage (`way_data_ram.v` and `way_tag_ram.v`) without reset loops, gating reads solely with explicit valid bits (`valid_bits.v`). This allowed Vivado to infer high-density **Distributed RAM (RAM64M / RAM64X1S LUTRAM)** in SLICEM primitives for both Way-0 and Way-1 data and tag arrays (using only 76 LUTRAMs). Discrete flip-flops are used only for state registers, valid bits (128 FFs), LRU state (64 FFs), and dirty bits (128 FFs), totaling only **482 FFs** (1.16% chip utilization).

### Timing and $F_{\max}$
- The direct-mapped critical path (7.820 ns, **127.88 MHz**) is dominated by wide multiplexer fan-out across the 19,000+ flip-flop array during tag checks and hit data selection.
- The 2-way set-associative cache achieves a shorter critical path (6.876 ns, **145.43 MHz**). The tag lookup from distributed RAM through the 22-bit comparator (`tag_comparator.v`) into FSM state decoding evaluates in only 6 logic levels, providing superior timing closure despite evaluating two ways in parallel.
